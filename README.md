# Tomorrow Happens — GitHub build

## Pagine
- `index.html` — home con marquee verticale e parola centrale.
- `notes.html` — Write your notes: parola + continuazione digitata.
- `gallery.html` — Overview performance: galleria randomica.
- `admin.html` — Write a word: modifica della parola cardine.

## Immagini
Inserisci le fotografie dell'evento in `assets/images/` con questi nomi:
`01.jpg` ... `08.jpg`

La galleria non usa una griglia: posizione e rotazione vengono generate casualmente dal browser.

## Parola cardine
`admin.html` salva la parola in `localStorage`. Non serve un database per la demo statica.
Per un sito multiutente o una parola condivisa tra dispositivi serve collegare il form a un backend/CMS.

## Deploy
Carica tutti i file nella repository GitHub e abilita GitHub Pages dalla branch principale.
